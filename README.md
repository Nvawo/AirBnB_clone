# AirBnB Clone

## Project Description

The AirBnB Clone project is a Python application that recreates some of the core functionality of the AirBnB website. The project is developed as a team project to practice Python programming, object-oriented programming, file handling, testing, and collaborative software development using Git and GitHub.

The first part of the project focuses on creating a command interpreter that allows users to interact with the application through a command-line interface.

## The Console

The command interpreter is a command-line interface that allows users to manage AirBnB objects. It provides commands for creating, displaying, updating, and deleting objects.

### How to Start It

The console can be started in interactive mode by running:

    ./console.py

The prompt will appear as:

    (hbnb)

The console can also be used in non-interactive mode by piping commands into it:

    echo "help" | ./console.py

### How to Use It

Once the console is running, commands can be entered at the `(hbnb)` prompt.

For example:

    $ ./console.py
    (hbnb) help
    (hbnb) quit
    $

The `quit` command exits the console, while the `help` command displays information about available commands.

### Examples

Interactive mode:

    $ ./console.py
    (hbnb) help
    (hbnb) quit
    $

Non-interactive mode:

    $ echo "help" | ./console.py
