# AirBnB Clone - Web Static

This project is part of the AirBnB clone project.

The `web_static` directory contains the HTML and CSS files used to build the static front-end of the AirBnB clone website.

## Task 0: Inline Styling

The first task creates an HTML page containing:

- A red header with a height of 70px.
- A green footer with a height of 60px.
- The text `Best School` centered vertically and horizontally in the footer.
- The footer positioned at the bottom of the page.

The task uses inline CSS styling as required.
